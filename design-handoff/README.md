# Tradelink design handoff

- `prototype.html`: the approved clickable prototype. Open it in a browser. Use the top bar to switch role, screen size and reset the demo.
- `design-system/README.md`: design principles, writing style and usage rules.
- `design-system/tokens.json`: colours for light and dark mode, type, spacing, radius and shadows.
- `design-system/components/`: reference previews and guidelines for each component.
- `logos/`: final logo files. Use the green logo on light backgrounds and the white logo on dark backgrounds.

All names, businesses, prices and figures in the prototype are fictional.
